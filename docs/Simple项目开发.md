# Simple 项目开发

本文以 Visual Studio Code 中的 ES4A 扩展为入口，介绍如何创建项目、设计窗口、编写代码和编译运行。Simple 语法见 [Simple 语言定义](Simple语言定义.md)。

## 准备开发环境

1. 准备 Windows 和 Visual Studio Code，安装 [ES4A 扩展](https://dwz.wsd.cx/es4a-vsix)。
2. 下载并解压 [完整 SDK](https://dwz.wsd.cx/es4a-sdk)，保留目录结构，无需配置全局环境变量。
3. 打开 ES4A 侧边栏，在“类库”视图执行“选择 SDK”，选择解压后的 SDK 根目录。

类库视图显示编译器、运行库后即可开始；移动 SDK 后重新选择目录。

## 第一个按钮应用

1. 在 ES4A“项目”标题栏创建项目，填写上级目录、项目目录名、包名和应用名称。
2. 包名可填 `com.example.hello`：至少两段，每段以英文字母开头，只含英文字母、数字和下划线。
3. 对主窗口执行“设计窗口布局”，拖入运行库“按钮”，名称设为 `按钮1`，文本设为“打招呼”。
4. 添加按钮的 `被单击` 事件，在事件体内调用提示函数。

```simple
事件 按钮1.被单击()
	显示提示框("你好，Simple")
结束 事件
```

如果编辑器已生成事件声明，只填写其中的函数调用。保存代码和设计器修改，打开项目中的 Simple 单元，按 `F5`。应用启动后点击按钮，应显示“你好，Simple”。

安装运行需要设备连接，见 [编译与运行](#编译与运行)。

## 项目与单元

已有项目通过“添加项目”选择其 `project.properties`。项目树中，在“单元”或其目录上右键，按需新建窗口、对象、接口或服务：

| 单元 | 用途 |
| --- | --- |
| 窗口 | 组织界面和界面事件 |
| 对象 | 组织实例成员或静态成员 |
| 接口 | 声明实现者需要提供的成员 |
| 服务 | 实现 Android 服务 |

通过项目树打开单元并编辑。窗口可使用“设计窗口布局”，其他单元编写对应代码；声明格式见 [程序单元](Simple语言定义.md#程序单元)。

“移除项目”只从列表移出，“删除项目”会删除项目目录。

### 改名与移动

单元的限定名由其在源码根目录下的路径决定。默认启用自动重构，同项目改名或移动时会更新可确认的关联引用，以及受影响的 `main`；单元改名还同步生命周期事件名，窗口改名同步根组件名。

自动重构不修改普通字符串或猜测动态名称。操作后检查修改、保存，再重新编译。拖拽单元移动只支持同一项目。

`es4a.automaticSync.unit` 控制单元自动重构，`es4a.automaticSync.package` 控制源码文件夹自动重构；关闭后需自行维护对应引用。

## 窗口与事件

在设计器中添加、选择和排列组件，通过属性框设置名称、文本、尺寸和布局；添加事件后，在代码编辑器中填写处理逻辑。代码和设计器修改分别保存，编译前应保存两边的修改。

容器决定其中子组件的排列方式。窗口和面板可以选择布局；滚动框只能直接放一个可视子组件，需要放多个时先加一个面板，再把组件放进面板。

尺寸可用 `长度_适应内容`、`长度_匹配父级` 或固定数值。设计器只显示简化效果，组件在设备上的实际行为以运行结果为准。文件末尾的属性区格式见 [属性区](Simple语言定义.md#属性区)。

## 资源与资产

在项目树的相应资源目录执行“导入资源”。右键项目选择“打开属性”，可设置应用图标、名称、版本、方向和主题。

| 内容 | 放在哪里 | 如何使用 |
| --- | --- | --- |
| 图片、布局等 Android 资源 | `res/` 的对应子目录，如 `res/drawable/icon.png` | 编译后通过 `R` 成员使用，如 `R.drawable_icon` |
| 应用图标 | Android 图片资源目录 | 在项目属性界面选择，配置文件对应 `icon=@drawable/icon` |
| 需要原样打包的文件 | `assets/` | 按调用函数要求填写文件名或路径，不使用 `R` 编号 |

## 引用已有类库

将已构建的扩展库安装到 SDK 的 `libraries/`，然后执行“ES4A: 刷新类库”。在类库树查看可用的对象、组件、属性、函数和事件；使用条件见各库 README，参数和行为见成员说明。

- **组件**：在设计器中添加，再设置属性、编写事件。
- **普通对象**：先创建实例，再调用实例成员。
- **静态函数**：通过类型调用，不会自动成为全局函数。

名称可使用短名称、限定名或别名，见 [包和限定名](Simple语言定义.md#包和限定名)。普通对象的完整调用示例见 [类库开发](Simple类库开发.md#普通对象)。

使用组件涉及权限时，按其说明处理运行时授权；类库声明权限不代表用户已授权。

## 编译与运行

| 操作 | 结果 |
| --- | --- |
| 右键项目，选择“编译应用” | 生成 APK |
| 右键项目，选择“调试应用” | 编译、安装并启动应用 |
| 打开项目中的 Simple 单元，按 `F5` | 编译、安装并启动该单元所属项目 |

编译无需设备。安装和启动前，连接一台已开启 USB 调试并接受电脑授权的真机，或启动 Android 模拟器；只保留本次使用的一个 ADB 目标。

运行后在终端查看结果。语言错误按报告的文件和行号定位；当前“调试应用”不提供断点、单步或变量查看。

最终 APK 为构建目录下的 `apks/signed.apk`，默认位于项目的 `build/` 下。需要命令行编译或离线选项时，见文末的 [命令行工具](#命令行工具)。

## 项目结构

项目创建后，可通过项目树管理单元和资源。需要核对磁盘文件时，目录通常如下：

```text
HelloSimple/
├─ project.properties
├─ src/
│  └─ com/example/hello/主窗口.simple
├─ res/
├─ assets/
└─ build/
```

右键项目选择“打开属性”可调整应用配置；需要直接查看配置文件时使用“定位属性”。项目入口 `project.properties` 使用 UTF-8，其中的目录路径相对于该文件所在目录：

```properties
main=com.example.hello.主窗口
name=你好 Simple
version.code=1
version.name=1.0
source=./src
res=./res
assets=./assets
build=./build
```

| 属性 | 填什么 |
| --- | --- |
| `main` | 主窗口完整限定名；其包名同时作为应用包名 |
| `name` | 应用显示名称，不改变最终 APK 文件名 |
| `version.code` | 整数版本号 |
| `version.name` | 显示给用户的版本文字 |
| `source` | 源码根目录，多个目录用逗号分隔 |
| `res` | Android 资源目录 |
| `assets` | 原样打包的文件目录 |
| `build` | 编译输出目录 |
| `icon`、`orientation`、`theme` | 图标、方向和主题，可通过项目属性界面选择 |

应明确填写 `main` 和 `source`。例如 `src/com/example/hello/主窗口.simple` 对应 `com.example.hello.主窗口`，代码中不再另写包名声明。

### 签名与清单配置

平时使用默认调试签名。发布应用时，设置 `key.location`，通过进程环境变量 `KEY_PASSWORD` 提供密码，使用 `key.alias` 指定别名；`key.password` 不生效。

密钥库位置和密码未同时提供时仍使用调试签名。选用发布签名后，证书无效或签名失败会中断构建；正式发布前确认实际签名。

AAR 要求清单占位符时，填写 `manifest.placeholder.<名称>=<值>`。`${applicationId}` 自动使用应用包名，不能覆盖。

类库要求配置清单宏时，在 `project.properties` 中按“对象简名.宏名”填写，例如 `示例对象.应用标识=my-app-id`。

## 排查编译与运行问题

| 问题 | 先检查 |
| --- | --- |
| 工具无法启动 | SDK 是否完整，JDK、Android 工具及两个 Simple JAR 是否在约定位置 |
| 主窗口找不到 | `main` 是否与源码根目录下的路径、文件名一致 |
| 类型或成员找不到 | 类库是否已安装，限定名和参数是否正确 |
| 类库树与编译结果不同 | 清单和 JAR 是否同一版本，更新后是否刷新并重新编译 |
| 资源编译失败 | 资源目录、名称、引用，以及终端第一条正式错误 |
| 安装或启动失败 | ADB 连接与授权、实际构建目录下的 `apks/signed.apk` 和脚本输出 |

语言错误按编译器报告的文件和行号定位；组件功能仍需在设备上验证。

## 命令行工具

日常开发通过项目树和 `F5` 操作即可。需要在扩展之外编译时，从 SDK 根目录执行：

```powershell
& .\utils\project\project.ps1 compile "D:\Projects\HelloSimple\project.properties"
& .\utils\project\project.ps1 debug "D:\Projects\HelloSimple\project.properties"
```

`compile` 只编译，`debug` 编译后安装并启动。两者都可添加 `-Offline` 禁止联网，或添加 `-RefreshDependencies` 刷新依赖，两个选项不能同时使用。离线构建需要依赖及元数据齐全，准备方式见 [准备和消费离线依赖](Simple类库开发.md#准备和消费离线依赖)。

命令只传入项目文件，不需要指定 APK 路径。完整 Gradle 日志位于构建目录的 `dependencies/resolution/gradle.log`。
