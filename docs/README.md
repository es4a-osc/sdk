# SDK 开发文档

按开发任务选择文档：

| 要做什么 | 阅读文档 |
| --- | --- |
| 查语法、类型、声明、表达式、事件或属性区 | [Simple 语言定义](Simple语言定义.md) |
| 选择 SDK，开发应用，使用项目工具与模板，编译运行 | [Simple 项目开发](Simple项目开发.md) |
| 用 Java 编写扩展对象或组件，从工程准备到构建交付 | [Simple 类库开发](Simple类库开发.md) |
| 用 JSON 定义分类、成员、图标、属性编辑器或设计器投影 | [类库清单定义](类库清单定义.md) |

运行库和扩展库的成员说明见 ES4A 类库树及对应清单；类库用途、使用条件与限制见各库 README。
