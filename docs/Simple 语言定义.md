## 语法记号

本文使用扩展巴科斯范式（EBNF）描述语法。

| 记号 | 含义 |
| --- | --- |
| `A \| B` | A 或 B |
| `( A )` | 分组 |
| `[ A ]` | A 可出现零次或一次 |
| `{ A }` | A 可出现零次或多次 |
| `标识符` | 词法产生的标识符 |
| `表达式` | 符合表达式语法的内容 |

语法规则中的中文关键字使用行内代码表示，例如 `变量`、`如果`、`结束`。示例使用 `simple` 代码块，以便编辑器按 Simple 语法着色。

## 词法结构

### 源文件和字符编码

Simple 源文件是纯文本文件，扩展名为 `.simple`。项目源码通常位于 `project.properties` 的 `source` 所指定目录内；单元的包名由源码根目录下的相对路径确定。

源文件采用 UTF-8 编码。Simple 区分大小写，因此 `名称`、`名称A` 和 `名称a` 是不同标识符，英文关键字也不能替代中文关键字。

### 行结束符和续行

Simple 是基于物理行的语言，通常以换行结束一条语句。编译器识别以下行结束符：

- CR（U+000D）；
- LF（U+000A）；
- CR 后接 LF。

```ebnf
行结束符 := CR | LF | CR LF
```

下划线 `_` 紧邻行结束符时表示续行。续行会让下一物理行继续属于当前语句。

```simple
变量 文本 为 文本型
文本 = "第一段" & _
	"第二段"
```

`_` 不能单独出现，也不能作为标识符的第一个字符。

### 空白符

下列字符属于空白符：

- TAB（U+0009）；
- VT（U+000B）；
- FF（U+000C）；
- 空格（U+0020）。

空白符用于分隔原本会连成一个令牌的字符。除字符串内部外，多余空白不改变语义。

### 令牌和最长匹配

扫描器总是尽可能读取最长的合法令牌。例如 `a<<b` 会被识别为标识符 `a`、左移运算符 `<<` 和标识符 `b`；`a< <b` 中的两个 `<` 则是两个独立运算符。

### 注释

单引号 `'` 开始单行注释，注释一直持续到当前物理行结束。字符串中的单引号不是注释起始符。

```simple
变量 数量 为 整数型  ' 这是注释
```

当前语言没有块注释，也不把 `REM` 识别为注释语句。

### 关键字

下列中文词组由当前扫描器保留，不能作为普通标识符。

| 类别 | 关键字 |
| --- | --- |
| 声明 | `别名`、`常量`、`变量`、`事件`、`函数`、`属性`、`过程`、`静态` |
| 参数 | `为`、`传值`、`传址` |
| 流程 | `执行`、`判断循环`、`直到`、`循环`、`每个`、`从`、`至`、`步进`、`下个`、`如果`、`则`、`否则如果`、`否则`、`判断`、`分支`、`结束`、`退出`、`位于`、`错误`、`触发事件` |
| 表达式 | `本对象`、`创建`、`空`、`类型检验`、`是`、`非`、`匹配`、`取反`、`且`、`或`、`异或` |
| 属性访问 | `获取`、`设置` |
| 类型 | `逻辑型`、`字节型`、`短整数型`、`整数型`、`长整数型`、`单精度小数型`、`双精度小数型`、`文本型`、`日期时间型`、`变体型`、`对象` |

`真` 和 `假` 是逻辑字面量。扫描器按字面量处理它们，不能作为标识符。

属性区另有一组只在属性区模式中生效的关键字：

`$属性`、`$资源`、`$窗口`、`$对象`、`$接口`、`$服务`、`$定义`、`$为`、`$结束`。

### 标识符

标识符必须以 Java 标识符起始字符开头，后续可使用 Java 标识符组成字符和下划线 `_`。美元符号 `$` 不能用于普通标识符，下划线不能作为首字符。

```ebnf
标识符 := Java标识符起始字符 { Java标识符组成字符 | _ }
```

中文字符可以组成标识符。

```simple
变量 当前数量 为 整数型
变量 局_响应文本 为 文本型
```

标识符不能与关键字或逻辑字面量完全相同。由于语言区分大小写，仅大小写不同的英文名称属于不同标识符，但不建议依赖这种差异命名。

### 字面量

```ebnf
字面量 := 整数字面量 | 浮点字面量 | 逻辑字面量 | 文本字面量 | 空字面量
```

#### 整数字面量

十进制整数字面量由数字组成。除单独的 `0` 外，不允许以 `0` 开头。十六进制整数字面量以大写 `&H` 开头，后接十六进制数字；当前扫描器要求前缀中的 `H` 为大写。

```ebnf
整数字面量 := 十进制整数字面量 | 十六进制整数字面量
十进制整数字面量 := 0 | 非零数字 { 数字 }
十六进制整数字面量 := &H 十六进制数字 { 十六进制数字 }
```

```simple
常量 十进制值 为 整数型 = 255
常量 十六进制值 为 整数型 = &HFF
常量 负值 为 整数型 = -12
```

负号不是字面量的一部分，`-12` 是一元负号作用于无符号字面量 `12`。

编译器根据数值范围把整数字面量解析为 `整数型` 或 `长整数型`，并在上下文允许时进行常量数值转换。

#### 浮点字面量

浮点字面量必须包含小数点，小数点后至少有一位数字；可以带科学计数法指数。

```ebnf
浮点字面量 := 十进制整数字面量 . 数字 { 数字 } [ 指数 ]
指数 := ( E | e ) [ + | - ] 十进制整数字面量
```

```simple
变量 比例 为 单精度小数型
比例 = 12.5

变量 距离 为 双精度小数型
距离 = 1.25E3
```

`.5`、`1.` 和没有小数点的 `1E3` 不符合当前扫描器的浮点字面量格式。

#### 逻辑字面量

```ebnf
逻辑字面量 := 真 | 假
```

两者的类型均为 `逻辑型`。

#### 文本字面量

文本字面量以双引号包围，不能跨越未续接的物理行。

```ebnf
文本字面量 := " { 文本字符 } "
```

当前可用的文本转义如下：

| 写法 | 值 |
| --- | --- |
| `\"` | 双引号 |
| `\\` | 反斜杠 |
| `\n` | 换行 |
| `\r` | 回车 |
| `\t` | 制表符 |
| `\uXXXX` | 四位十六进制 Unicode 字符 |

```simple
变量 消息 为 文本型
消息 = "第一行\n第二行：\"完成\""
```

!> 当前不支持 `\f` 换页转义。其他未知转义可能丢弃反斜杠并保留后面的字符，请不要依赖这种容错行为。

#### 空字面量

`空`是由上下文决定类型的默认值字面量，不固定属于某一种数据类型。编译器会先确定赋值目标或参数类型，再生成对应的默认值。

```simple
变量 当前窗口 为 窗口
当前窗口 = 空

变量 时间 为 日期时间型
时间 = 空

变量 附加参数 为 变体型
附加参数 = 空
```

`空`转换到不同目标类型时生成相应的默认值：逻辑型为 `假`，数值型为零，文本型为 `""`，对象、日期时间和数组为无实例引用，变体型为 `UninitializedVariant`。因此，`空`可以赋给或传递给 `变体型`，生成的值不是 Java `null`。

### 分隔符

```ebnf
分隔符 := ( | ) | , | :
```

冒号 `:` 与物理行结束符一样可以结束一条语句。为保证代码可读性，通常一行只写一条语句。

### 运算符

Simple 使用以下符号或关键字运算符：

```text
^  +  -  *  /  \  %  &  <<  >>
<  <=  =  <>  >=  >  是  非  匹配  类型检验 ... 是
取反  且  或  异或  .
```

## 类型和值

```ebnf
类型 := 非数组类型 | 数组类型
非数组类型 :=
	逻辑型 | 字节型 | 短整数型 | 整数型 | 长整数型 |
	单精度小数型 | 双精度小数型 | 文本型 | 日期时间型 |
	变体型 | 对象 | 具体对象类型
```

### 基本类型

| Simple 类型 | 含义 | 值域或实现 |
| --- | --- | --- |
| `逻辑型` | 逻辑值 | `真`、`假` |
| `字节型` | 8 位有符号整数 | -128 至 127 |
| `短整数型` | 16 位有符号整数 | -32768 至 32767 |
| `整数型` | 32 位有符号整数 | -2147483648 至 2147483647 |
| `长整数型` | 64 位有符号整数 | -9223372036854775808 至 9223372036854775807 |
| `单精度小数型` | 32 位单精度浮点数 | IEEE 754 |
| `双精度小数型` | 64 位双精度浮点数 | IEEE 754 |
| `文本型` | Unicode 字符序列 | 可以为空文本 `""` |
| `日期时间型` | 日期和时间值 | 运行时映射为 `java.util.Calendar` |
| `变体型` | 可表示任一其他数据类型值的不相交联合 | 当前运行库用不同 Variant 包装类保存实际类型和值；`空`转换为未初始化变体值 |

`逻辑型` 在数值转换中使用 `真 = -1`、`假 = 0` 的规则。逻辑运算时仍按逻辑值处理。

### 数组类型

数组保存相同元素类型的值，可以有一维或多维。每个维度中的数值表示元素数量，下标从 `0` 开始；长度为 `N` 的一维数组，有效下标是 `0` 至 `N - 1`。

```ebnf
数组类型 := 非数组类型 ( [ 表达式 { , 表达式 } ] | { , } )
```

有尺寸的数组声明会直接创建定长数组；只有逗号的形式声明动态数组的维数。

```simple
' 一维定长数组，包含 2 个元素
变量 名称 为 文本型(2)

' 二维定长数组，包含 2 × 3 个元素
变量 表格 为 整数型(2, 3)

' 一维动态数组
变量 动态列表 为 文本型()
动态列表 = 创建 文本型(10)

' 二维动态数组
变量 动态表格 为 整数型(,)
动态表格 = 创建 整数型(4, 5)
```

数组下标使用圆括号，维数必须与声明相符，下标表达式必须可以转换为 `整数型`。

```simple
表格(1, 2) = 100
```

没有尺寸的动态数组变量默认是空数组引用；声明时给出尺寸的数组会立即分配，元素使用各自类型的默认值。`空`转换为数组类型时表示空数组引用。两个数组只有元素类型和维数完全相同时才是同一数组类型。

### 对象类型

```ebnf
对象类型 := 对象 | 限定标识符
```

`对象` 是通用对象类型；类库对象或项目单元的限定名表示具体对象类型。对象值是实例引用，也可以是 `空`。

对象支持实现继承和接口实现。继承关系不写在用户代码声明中，而保存在文件末尾的属性区。

非接口对象有两个约定事件：对象首次加载时触发静态的 `加载` 事件；创建对象实例时触发实例的 `初始化` 事件。

当前对象到对象的转换由编译器生成运行时类型检查。目标类型不兼容时会在运行时失败。

### 默认值

变量声明后会取得其类型的默认值。

| 类型 | 默认值 |
| --- | --- |
| `逻辑型` | `假` |
| `字节型`、`短整数型`、`整数型`、`长整数型` | `0` |
| `单精度小数型`、`双精度小数型` | `0.0` |
| `文本型` | `""` |
| `日期时间型` | `空` |
| `变体型` | 未初始化变体值 |
| 动态数组 | `空` |
| 定长数组 | 已分配数组，各元素为元素类型默认值 |
| `对象` 和具体对象类型 | `空` |

当前编译器使用 `UninitializedVariant` 单例表示 `变体型` 的默认值。`空`转换为 `变体型` 时也会生成这个值，因此它不是 Java `null`，也不同于包含数值零、逻辑假或空文本的变体值。

## 类型转换

赋值、参数传递和运算符求值会按上下文插入隐式类型转换。编译期允许转换，不代表所有运行时值都能成功转换。

### 转换总表

表中“允许”表示编译器可生成转换；“相同”表示无需转换；“运行时检查”表示值不兼容时会在运行时失败；“禁止”表示编译期错误。

| 来源类型 | 逻辑 | 数值 | 文本 | 日期时间 | 变体 | 数组 | 对象 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `逻辑型` | 相同 | 允许 | 允许 | 禁止 | 允许 | 禁止 | 禁止 |
| 任一数值类型 | 允许 | 允许 | 允许 | 禁止 | 允许 | 禁止 | 禁止 |
| `文本型` | 运行时检查 | 运行时检查 | 相同 | 禁止 | 允许 | 禁止 | 禁止 |
| `日期时间型` | 禁止 | 禁止 | 禁止 | 相同 | 允许 | 禁止 | 禁止 |
| `变体型` | 运行时检查 | 运行时检查 | 运行时检查 | 运行时检查 | 相同 | 运行时检查 | 运行时检查 |
| 数组 | 禁止 | 禁止 | 禁止 | 禁止 | 允许 | 仅完全相同类型 | 禁止 |
| 对象类型 | 禁止 | 禁止 | 禁止 | 禁止 | 允许 | 禁止 | 运行时检查或相同 |

### 逻辑与数值转换

| 转换 | 结果 |
| --- | --- |
| `假` → 数值 | `0` 或 `0.0` |
| `真` → 整数 | `-1` |
| `真` → 浮点数 | `-1.0` |
| 数值 `0` → `逻辑型` | `假` |
| 非零数值 → `逻辑型` | `真` |

不同数值类型之间允许互转。转成更窄的整数类型可能丢失高位；整数与浮点数互转可能丢失精度；浮点数转整数时截去小数部分。

从窄到宽的通常顺序为：

```text
逻辑型 → 字节型 → 短整数型 → 整数型 → 长整数型 → 单精度小数型 → 双精度小数型
```

“更宽”只表示通常能表达更大范围，不保证跨整数和浮点类型时保留全部有效数字。

### 文本转换

- 逻辑值转文本得到 `"真"` 或 `"假"`。
- 整数转文本使用十进制格式。
- 浮点数转文本使用运行库的浮点文本格式。
- 文本 `"真"`、`"假"` 可转成逻辑值；数值文本也可按零和非零转成逻辑值。
- 文本转数值时必须是运行库能够解析的数值格式，否则产生运行时错误。

```simple
变量 数量 为 整数型
数量 = "12"

变量 信息 为 文本型
信息 = 数量
```

### 变体型转换

普通值转成 `变体型` 时，运行库创建相应的变体包装值。变体转成具体类型时，由变体当前保存的实际类型和值决定；不兼容会产生运行时错误。

```simple
变量 值 为 变体型
值 = 100

变量 数量 为 整数型
数量 = 值
```

日期、数组、对象和各类标量值都可以转换为变体。`空`也可以转换为 `变体型`，结果为未初始化变体值：

```simple
变量 附加参数 为 变体型
附加参数 = 空
```

该转换不能生成 Java `null`。运行库边界若收到 Java `null`，应明确转换成未初始化变体值或按具体 API 报错，不能把空引用直接当作一个合法 `Variant` 实例继续调用。

### `空` 的转换规则

`空` 是受上下文约束的默认值字面量。编译器先根据赋值目标、形参或其他上下文确定目标类型，再生成该类型的默认值。

```simple
变量 数量 为 整数型
数量 = 空          ' 结果为 0

变量 文本 为 文本型
文本 = 空          ' 结果为 ""

变量 数组 为 整数型()
数组 = 空          ' 结果为空数组引用

变量 参数 为 变体型
参数 = 空          ' 结果为未初始化变体值
```

同一规则适用于赋值、函数和过程实参、事件实参以及动态调用实参。例如 `变体型`形参可以接收 `空`：

```simple
投递消息("执行成功", 空)
```

!> `空` 可以赋给 `变体型`，但当前运行库尚未完整支持未初始化变体值的比较。直接执行 `附加参数 = 空` 仍可能产生转换错误。

## 程序单元

### 单元结构

每个 `.simple` 文件定义一个程序单元。单元由用户代码区和文件末尾的属性区组成。

```ebnf
程序单元 := { 别名声明 } { 顶层声明 } 属性区
```

用户代码区包含声明和实现。属性区描述单元种类、继承、接口和设计器组件，由 IDE 维护；普通编程时不应直接编辑。别名建议集中写在文件开头、其他顶层声明之前；当前解析器虽然接受别名与声明交错，但不要依赖这种宽松行为。

### 包和限定名

程序单元必须属于包。包由源码目录结构决定，可逐层嵌套。单元限定名由包名和文件名用点号连接。

例如文件：

```text
src/example/app/主窗口.simple
```

在源码根 `src` 下的限定名为：

```text
example.app.主窗口
```

限定名用于区分不同包中的同名单元，也用于属性区的 `基础对象` 和 `实现接口`。

### 单元种类

当前支持四种程序单元：

| 单元种类 | 属性区标记 | 含义 |
| --- | --- | --- |
| 窗口 | `$资源 $窗口` | 界面窗口及其组件树 |
| 对象 | `$资源 $对象` | 普通对象，可指定基础对象和实现接口 |
| 接口 | `$资源 $接口` | 只声明契约，不包含实现体 |
| 服务 | `$资源 $服务` | Android 服务单元 |

窗口的基础类型由编译器根据单元种类设置。对象单元的继承关系由属性区显式指定。

?> 线程没有独立程序单元。需要自定义线程时，请使用对象单元，并把 `基础对象` 设为 `simple.runtime.collections.线程`。

## 声明

Simple 不支持隐式声明。变量、常量、函数、过程、属性和事件都必须先声明。

```ebnf
顶层声明 :=
	变量声明 | 常量声明 | 函数声明 | 过程声明 |
	属性声明 | 事件声明 | 事件处理声明
```

### 别名声明

```ebnf
别名声明 := 别名 标识符 = 限定标识符
```

别名为完全限定名建立短名称。

```simple
别名 基础线程 = simple.runtime.collections.线程
```

同一作用域不能重复定义别名，也不能覆盖已有的同名符号。为保持单元结构稳定，别名应集中写在文件开头、其他声明之前。

### 变量声明

```ebnf
变量声明 := [ 静态 ] 变量 标识符 为 类型 { , 标识符 为 类型 }
```

顶层变量是对象成员。普通顶层变量按对象实例分别保存；`静态 变量` 由所有实例共享。

```simple
变量 当前名称 为 文本型
静态 变量 实例数量 为 整数型
变量 宽度 为 整数型, 高度 为 整数型
```

函数、过程、事件处理器以及属性的获取器和设置器内可以声明局部变量。局部变量不能使用 `静态`。

```simple
过程 计算()
	变量 结果 为 整数型
结束 过程
```

定长数组可在声明时给出每维元素数，动态数组只声明维数。

### 常量声明

```ebnf
常量声明 := 常量 标识符 为 非数组类型 = 常量表达式
	{ , 标识符 为 非数组类型 = 常量表达式 }
```

常量只能在程序单元顶层声明，必须在声明时赋值。常量表达式只能依赖字面量、已有常量和可在编译期求值的运算。

```simple
常量 最小值 为 整数型 = 0
常量 最大值 为 整数型 = 100, 默认值 为 整数型 = 最大值 / 2
```

### 函数声明

```ebnf
函数声明 :=
	[ 静态 ] 函数 标识符 ( [ 形式参数 ] ) 为 类型
	{ 语句 }
	结束 函数
```

函数有返回值。函数体内隐式存在一个与函数同名、类型为返回类型的可赋值局部量；函数结束时该量的值就是返回值。

```simple
函数 相加(左值 为 整数型, 右值 为 整数型) 为 整数型
	相加 = 左值 + 右值
结束 函数
```

函数不能嵌套。顶层普通函数属于实例，`静态 函数` 属于对象本身。

### 过程声明

```ebnf
过程声明 :=
	[ 静态 ] 过程 标识符 ( [ 形式参数 ] )
	{ 语句 }
	结束 过程
```

过程没有返回值，其他规则与函数相同。

```simple
过程 显示结果(内容 为 文本型)
	显示提示框(内容)
结束 过程
```

### 参数

```ebnf
形式参数 := 形式参数项 { , 形式参数项 }
形式参数项 := [ 传值 | 传址 ] 标识符 为 类型
```

不写传递方式时默认为 `传值`。

- `传值`：被调用方修改形参不会改变调用方变量。
- `传址`：实际参数为可赋值左值时，被调用方的修改会回写调用方变量。
- 传给 `传址` 参数的实际参数若不是左值，编译器会按临时值处理，修改不会回写。

```simple
过程 增加(传址 数值 为 整数型)
	数值 = 数值 + 1
结束 过程
```

实参数量必须与形参数量一致，每个实参必须能转换为对应形参类型。

### 属性声明

```ebnf
属性声明 :=
	属性 标识符 为 类型
	[ 获取
		{ 语句 }
	结束 获取 ]
	[ 设置
		{ 语句 }
	结束 设置 ]
	结束 属性
```

属性至少要有获取器或设置器。

- 只有 `获取` 的属性是只读属性。
- 只有 `设置` 的属性是只写属性。
- 同时具有二者的属性可读写。

获取器和设置器内都隐式存在一个与属性同名的局部量。获取器通过给它赋值返回结果；进入设置器时，它保存调用者传入的新值。

```simple
变量 成_标题 为 文本型

属性 标题 为 文本型
	获取
		标题 = 成_标题
	结束 获取
	设置
		成_标题 = 标题
	结束 设置
结束 属性
```

### 事件声明

```ebnf
事件声明 :=
	事件 标识符 ( [ 形式参数 ] )
	结束 事件
```

事件声明定义对象可以触发的事件，本身没有执行体。

```simple
事件 数据改变(新值 为 整数型)
结束 事件
```

### 事件处理声明

```ebnf
事件处理声明 :=
	事件 标识符 . 标识符 ( [ 形式参数 ] )
	{ 语句 }
	结束 事件
```

点号前是事件来源，点号后是事件名。来源可以是当前单元名称，也可以是当前对象的组件或对象成员。

```simple
事件 主窗口.初始化()
	' 窗口初始化代码
结束 事件

事件 按钮1.被单击()
	显示提示框("已单击")
结束 事件
```

事件处理器不能像过程一样直接调用；它由事件系统在对应事件发生时调用。

### 接口中的声明

接口单元只允许：

- 别名；
- 常量；
- 没有函数体的函数声明；
- 没有过程体的过程声明。

接口函数和过程仍以 `结束 函数` 或 `结束 过程` 结束，但中间不能写实现语句。当前解析器不接受接口中的变量、属性和事件声明。

## 作用域

### 包和单元作用域

对象单元在所属包中定义，可从其他包通过完全限定名访问。同一包内不能定义同名对象，不同包可以有同名单元。

### 成员作用域

顶层变量、常量、函数、过程、属性和事件都是对象成员。函数和过程可以使用同一名称，但只能按参数个数重载；参数个数相同时，即使参数类型、返回类型或传递方式不同，也属于重复定义。对象函数和实例函数不能组成同一重载组。变量、常量、属性和事件不支持重载，也不能与函数或过程重载组同名。

派生对象可以覆盖基础对象的函数、过程、属性和事件，但不能重新定义基础对象已有的数据成员。调用函数或过程时，编译器先按名称和参数个数查找当前对象；当前对象没有对应参数个数时，再继续查找基础对象。

### 参数和局部作用域

参数的作用域是对应函数、过程、事件处理器或属性访问器。

局部变量从声明处开始生效，持续到当前语句块结束，并在嵌套块中可见。同一语句块不能重复声明同名局部变量；内层语句块可以用同名变量遮蔽外层局部变量或对象成员。

```simple
变量 结果 为 文本型

过程 测试()
	变量 结果 为 整数型
	结果 = 1

	如果 真 则
		变量 结果 为 文本型
		结果 = "内层"
	结束 如果
结束 过程
```

## 表达式

### 运算符优先级

下表按当前编译器的优先级从高到低排列。成员限定 `.` 和赋值由相应语法上下文处理，不计入表中的运算符层级。

| 优先级 | 运算符 | 说明 |
| --- | --- | --- |
| 12 | `^` | 幂 |
| 11 | 一元 `+`、一元 `-` | 正号、负号 |
| 10 | `*`、`/` | 乘法、除法 |
| 9 | `\` | 整除 |
| 8 | `%` | 求模（余数） |
| 7 | `+`、`-` | 加法、减法 |
| 6 | `&` | 文本连接 |
| 5 | `<<`、`>>` | 位移 |
| 4 | `<`、`<=`、`=`、`<>`、`>=`、`>`、`是`、`非`、`匹配`、`类型检验 ... 是` | 比较和类型判断 |
| 3 | `取反` | 逻辑或按位取反 |
| 2 | `或`、`异或` | 逻辑或按位或、异或 |
| 1 | `且` | 逻辑或按位与 |

同一优先级的运算通常从左到右计算；`^` 按右结合理解。

!> 当前 `或`、`异或` 的优先级高于 `且`。混用三者时请始终使用括号明确顺序。

### 基本表达式

```ebnf
基本表达式 :=
	本对象 | 标识符 | 限定标识符 | 字面量 |
	括号表达式 | 调用或数组表达式 | 创建表达式
```

#### `本对象`

`本对象` 在实例函数、实例过程、属性和事件处理器中表示当前对象实例。静态函数或静态过程中不能依赖实例对象。

```simple
变量 当前 为 对象
当前 = 本对象
```

#### 限定标识符

```ebnf
限定标识符 := 标识符 { . 标识符 }
```

点号可以限定包、单元、对象成员或组件属性。

```simple
example.app.主窗口
编辑框1.文本
布局.行数
```

包限定名必须从全局命名空间开始；对象成员限定则由点号左侧表达式的类型决定。

#### 调用和数组访问

```ebnf
调用或数组表达式 := 限定标识符 ( [ 实际参数 ] )
实际参数 := 表达式 { , 表达式 }
```

同一语法同时表示函数/过程调用和数组访问，编译器根据标识符类型判定。

- 数组访问的索引数量必须与数组维数相同。
- 函数或过程调用的实参数量必须与形参数量相同。
- 参数和索引按从左到右求值。
- 函数调用可以作为值；过程调用没有结果值。

```simple
表格(1, 2) = 3
显示结果(表格(1, 2))
```

#### 括号表达式

```ebnf
括号表达式 := ( 表达式 )
```

```simple
变量 结果 为 整数型
结果 = 2 ^ (4 + 1)
```

#### 创建表达式

```ebnf
创建表达式 :=
	创建 对象类型
	| 创建 对象类型 位于 表达式
	| 创建 非数组类型 ( 表达式 { , 表达式 } )
```

`创建` 用于创建对象、组件或动态数组。

```simple
变量 请求 为 HTTP请求
请求 = 创建 HTTP请求

变量 标签1 为 标签
标签1 = 创建 标签 位于 本对象

变量 数组 为 整数型()
数组 = 创建 整数型(10)
```

创建对象时先分配实例并初始化成员默认值，再触发初始化事件。创建组件时必须用 `位于` 指定组件容器，组件先加入容器，再触发初始化事件。创建动态数组时，每个维度的尺寸由实参给出，元素按元素类型默认值初始化。

### 算术表达式

#### 幂 `^`

`左值 ^ 右值` 计算乘方。两侧类型相同且不是文本时保留该类型；其他组合转为 `变体型`。结果不会固定转换为 `双精度小数型`。

#### 一元正负号

一元 `+` 保持数值，一元 `-` 取相反数，结果类型与操作数类型相同。可稳定使用的操作数是数值类型或 `变体型`。

!> 当前检查可能允许 `文本型` 通过，但随后仍会编译失败；这不表示语言支持对文本使用一元正负号。

#### 乘法和除法

`*` 进行乘法。两侧类型相同且不是文本时保留原类型；类型不同或包含文本时转为 `变体型`。

`/` 进行普通除法。操作数转换为数值类型，结果固定为 `双精度小数型`。除数为零时可能产生运行时错误；浮点溢出、下溢和非有限值遵循运行时浮点规则。

#### 整除

反斜杠 `\` 进行整除。同类型操作数保留原类型，混合类型或文本使用 `变体型`，结果不固定为 `整数型`。除数为零会产生运行时错误。

```simple
变量 结果 为 整数型
结果 = 12.5 \ 3.1
```

#### 求模运算符 `%`

`%` 返回除法余数。同类型且不是文本时保留原类型，混合类型或文本使用 `变体型`。

```simple
变量 余数 为 整数型
余数 = 11 % 3
```

#### 加减

`+` 和 `-` 执行数值加减。同类型且不是文本时保留原类型；类型不同或包含文本时使用 `变体型` 运算。文本拼接请使用 `&`。

### 文本连接

`&` 把左右操作数转为 `文本型` 后连接，结果为 `文本型`。

```simple
变量 信息 为 文本型
信息 = "数量：" & 2 + 5
```

因为加法优先级高于连接，示例结果为 `"数量：7"`。

### 位移

`<<` 左移，`>>` 有符号右移。当前实现会把两侧转换为 `变体型`，结果也是 `变体型`。

### 比较

#### 有序比较和相等比较

```text
<  <=  =  <>  >=  >
```

比较结果均为 `逻辑型`。同类型操作数直接使用该类型的比较实现；不同类型先转换为 `变体型`。文本按字典顺序比较。

!> `日期时间型` 当前只可稳定用于 `=` 和 `<>`。使用 `<`、`<=`、`>` 或 `>=` 会在编译期报错。

赋值语句也使用 `=`，解析器根据它在语句中的位置区分赋值和相等比较。

#### 引用同一性 `是` 和 `非`

`是` 判断两个数组或对象引用是否指向同一实例；`非` 判断是否不指向同一实例。它们不比较对象成员内容。

```simple
如果 左对象 是 右对象 则
	' 两个引用指向同一实例
结束 如果
```

#### 文本匹配 `匹配`

`匹配` 将两侧转换为文本，并使用 Java 正则表达式语义判断左侧文本是否匹配右侧模式。

```simple
变量 成功 为 逻辑型
成功 = "foof" 匹配 "f.*f"
```

#### 类型判断

```ebnf
类型判断表达式 := 类型检验 表达式 是 类型
```

结果表示运行时值是否与目标类型兼容。

```simple
变量 值 为 变体型
值 = 1

如果 类型检验 值 是 整数型 则
	' 值当前保存整数
结束 如果
```

### 逻辑和按位运算

`取反`、`且`、`或`、`异或` 同时用于逻辑值和整数值。

- 操作数为 `逻辑型` 时执行逻辑运算。
- 操作数为整数类时执行按位运算。
- 两个整数操作数类型相同时保留该类型，类型不同时转换为 `变体型`。

逻辑型 `且` 和 `或` 使用短路求值：`且` 的左侧为假、或 `或` 的左侧为真时，不求右侧。`异或` 会求两侧。编写带副作用的右操作数时必须考虑这一点。

!> 当前检查可能放过两个相同的非整数标量，但这不表示语言支持这种写法，请勿依赖。

### 赋值表达式

```ebnf
赋值表达式 := 左值 = 表达式
左值 := 变量 | 可写属性 | 数组元素
```

右侧值会转换为左侧类型。常量、只读属性、函数调用结果和普通计算表达式不能作为左值。

```simple
变量 数量 为 整数型
数量 = "12"
数组(0) = 数量
```

## 语句

函数、过程、事件处理器和属性访问器的执行体由语句和局部变量声明组成。

```ebnf
语句 :=
	执行循环语句 | 表达式语句 | 退出语句 | 循环每个语句 |
	循环至语句 | 如果语句 | 错误处理语句 | 触发事件语句 |
	判断语句 | 判断循环语句 | 局部变量声明
```

### 后测循环：`执行 ... 判断循环`

```ebnf
执行判断循环语句 :=
	执行
		{ 语句 }
	判断循环 表达式
```

循环体至少执行一次；每轮结束后求条件，条件为 `真` 时继续。

```simple
变量 计数 为 整数型
执行
	计数 = 计数 + 1
判断循环 计数 < 20
```

### 后测循环：`执行 ... 直到`

```ebnf
执行直到语句 :=
	执行
		{ 语句 }
	直到 表达式
```

循环体至少执行一次；条件为 `假` 时继续，为 `真` 时停止。

```simple
变量 计数 为 整数型
执行
	计数 = 计数 + 1
直到 计数 >= 20
```

### 前测循环：`判断循环`

```ebnf
判断循环语句 :=
	判断循环 表达式
		{ 语句 }
	结束 判断循环
```

进入循环体前先求条件，条件为 `真` 时执行。

### 表达式语句

表达式语句只能是赋值或调用。

```simple
数量 = 数量 + 1
显示结果(数量)
```

单独写数组读取、常量或普通算术表达式不是合法语句。

### 退出

```ebnf
退出语句 := 退出 [ 执行 | 事件 | 循环 | 函数 | 属性 | 过程 | 判断循环 ]
```

不带类别时，`退出` 优先退出最近的循环；没有外层循环时退出当前函数、过程、属性访问器或事件处理器。

带类别时，类别必须与可退出的外层结构相符。

```simple
如果 取消 则
	退出 过程
结束 如果
```

### 遍历数组或集合

```ebnf
循环每个语句 :=
	循环 每个 标识符 从 表达式
		{ 语句 }
	下个 [ 标识符 ]
```

循环变量必须事先声明，其类型必须与数组元素或集合元素赋值兼容。

```simple
变量 项目 为 变体型
循环 每个 项目 从 集合
	显示结果(项目)
下个 项目
```

### 计数循环

```ebnf
循环至语句 :=
	循环 标识符 = 初值表达式 至 终值表达式 [ 步进 步长表达式 ]
		{ 语句 }
	下个 [ 标识符 ]
```

循环变量必须事先声明。初值在进入循环时赋给循环变量；终值和步长只求值一次。省略 `步进` 时步长为 1。

- 正步长在循环变量越过终值后结束。
- 负步长在循环变量反向越过终值后结束。

```simple
变量 i 为 整数型
循环 i = 10 至 1 步进 -1
	显示结果(i)
下个 i
```

### 条件语句

#### 单行形式

```ebnf
单行如果语句 := 如果 表达式 则 同行语句 [ 否则 同行语句 ]
```

单行分支只允许赋值、调用、`退出` 或 `触发事件`。

```simple
如果 数量 > 0 则 结果 = "有数据" 否则 结果 = "无数据"
```

#### 多行形式

```ebnf
多行如果语句 :=
	如果 表达式 则
		{ 语句 }
	{ 否则如果 表达式 则
		{ 语句 } }
	[ 否则
		{ 语句 } ]
	结束 如果
```

条件按顺序求值，只执行第一个为真的分支；都不为真时执行可选的 `否则`。

### 错误处理

```ebnf
错误处理语句 :=
	位于 错误
	{ 分支 错误类型 { , 错误类型 }
		{ 语句 } }
	[ 分支 否则
		{ 语句 } ]
	结束 错误
```

错误处理语句必须是函数、过程、事件处理器或属性访问器的最后一条语句，每个执行体最多一个。

运行时错误从发生位置向调用栈上层寻找匹配的错误处理段。`分支 否则` 捕获前面未匹配的运行时错误，并且必须放在最后。

```simple
函数 读取元素(数组 为 整数型(), 索引 为 整数型) 为 整数型
	读取元素 = 数组(索引)

	位于 错误
		分支 索引超出界限错误
			读取元素 = 0
		分支 否则
			读取元素 = -1
	结束 错误
结束 函数
```

### 触发事件

```ebnf
触发事件语句 := 触发事件 标识符 ( [ 实际参数 ] )
```

只能在声明该事件的对象实例函数、过程或属性中触发事件。实参数量和类型必须与事件声明一致。

```simple
事件 数据改变(值 为 整数型)
结束 事件

过程 更新(值 为 整数型)
	触发事件 数据改变(值)
结束 过程
```

### 多分支判断

```ebnf
判断语句 :=
	判断 表达式
	{ 分支 分支表达式 { , 分支表达式 }
		{ 语句 } }
	[ 分支 否则
		{ 语句 } ]
	结束 判断

分支表达式 :=
	表达式
	| 是 比较运算符 表达式
	| 表达式 至 表达式
```

编译器从上到下检查分支，只执行第一个匹配分支，然后结束整个判断。分支可以是：

- 一个或多个逗号分隔的相等值；
- `下界 至 上界` 范围；
- `是 <`、`是 <=`、`是 =`、`是 <>`、`是 >=`、`是 >` 比较；
- 最后的 `分支 否则`。

```simple
判断 数量
	分支 是 < 0
		文本 = "负数"
	分支 0
		文本 = "零"
	分支 1, 2
		文本 = "一或二"
	分支 3 至 100
		文本 = "三到一百"
	分支 否则
		文本 = "较大数"
结束 判断
```

## 属性区

### 作用和边界

每个 `.simple` 文件末尾必须有属性区。属性区是源文件的一部分，但主要由 IDE 和设计器维护。

属性区决定：

- 程序单元种类；
- 对象的基础对象和实现接口；
- 窗口的组件树；
- 组件的设计期属性值。

用户代码区和属性区由扫描器分别读取。属性区关键字只在属性区中合法。

### 窗口单元

```ebnf
窗口属性区 :=
	$属性
		$资源 $窗口
		$定义 单元名 $为 窗口
			{ 组件属性 | 组件定义 }
		$结束 $定义
	$结束 $属性

组件定义 :=
	$定义 组件名 $为 组件类型
		{ 组件属性 | 组件定义 }
	$结束 $定义

组件属性 := 限定属性名 = 表达式
```

```simple
$属性
	$资源 $窗口
	$定义 主窗口 $为 窗口
		标题 = "示例"
		$定义 按钮1 $为 按钮
			文本 = "确定"
		$结束 $定义
	$结束 $定义
$结束 $属性
```

嵌套 `$定义` 表示组件容器中的子组件。属性名可以使用点号表示复合属性，例如 `布局.行数`。组件实现有默认值时，属性区通常只保存不同于默认值的值。

### 对象单元

```ebnf
对象属性区 :=
	$属性
		$资源 $对象
		[ 基础对象 = 完全限定对象名 ]
		{ 实现接口 = 完全限定接口名 }
	$结束 $属性
```

```simple
$属性
	$资源 $对象
	基础对象 = simple.runtime.collections.线程
	实现接口 = 示例.可运行, 示例.可停止
$结束 $属性
```

`基础对象` 和 `实现接口` 必须使用完全限定名。实现多个接口时写在同一 `实现接口` 行，并用逗号分隔。

### 接口单元

```simple
$属性
	$资源 $接口
$结束 $属性
```

接口属性区没有其他配置项。

## 使用注意事项

- `空`会先根据赋值目标或参数类型生成相应默认值；转为 `变体型` 时使用 `UninitializedVariant`，不是 Java `null`。
- 未初始化变体值与 `空`的比较尚不完整，相关表达式可能产生转换错误。
- `是`和`非`只用于数组、对象或可执行同一性判断的`变体型`，不要用于普通标量。
- `且`、`或`和`异或`只应连接两个逻辑值，或两个整数类标量。
- 一元正负号不要用于`文本型`；即使当前检查未立即报错，代码仍可能在编译后续阶段失败。
- `日期时间型`目前只稳定支持`=`和`<>`比较。
- 别名应集中写在单元开头；属性区应由 ES4A 维护，不建议手工改写。
